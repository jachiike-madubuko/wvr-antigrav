# Galaxy UI — Student Interest Exploration & Vetting Platform

A high-fidelity spatial web application and classroom interest vetting engine built from the ground up to replace static tabular student grouping with an interactive celestial canvas.

## ✨ Core Features

- **Spatial Galaxy Canvas**: 8 curated interest galaxies (*Space & Astrophysics, Ballet & Kinetic Dance, Entomology & Living Biomes, Robotics, Marine Biology, Paleontology, Culinary Chemistry, Acoustics*) rendered with real-time starfields and nebula dust.
- **Dynamic Drag-and-Drop Assignment**: Direct student manipulation from the class dock into orbital clusters.
- **Affinity & Compatibility Indicator**:
  - 🟢 **Preference Match (Green Aura + Rank Badge)**: When dropped into a galaxy within the student's submitted Top 5.
  - 🔴 **Mismatch Alert (Red Ring Warning)**: Instant visual notification when a student is dropped into a group outside their choices.
- **Pop-In Spawn Animations**: Spring-based visual transitions and synthesized Web Audio sound feedback upon assignment.
- **Teacher Curation & Overlap Analysis**:
  - Live overlap frequency histogram showing which topics have the highest student overlap.
  - Vetting controls to curate down to 7–8 active classroom galaxies.
  - Discard pile for low-educational or slacker topic submissions.
- **Cadence & Rotation Simulator**:
  - Monthly rotation countdown.
  - "Advance Cycle" simulation modeling student interest shifts over time.
  - Student intake modal for updating Top 5 ranked preferences.
- **Celestial Skins Catalog**: Equippable student avatars (*Astro-Pioneer, Cyber-Visor, Nebula-Crown, Solar-Flare, Bio-Explorer*).

## 🚀 Getting Started

Clone the repository and open `index.html` in any modern web browser:

```bash
# Clone repository
git clone https://github.com/jachiike-madubuko/wvr-antigrav.git
cd wvr-antigrav

# Open in browser (macOS)
open index.html
```

No external server, build step, or dependencies required.
